第一次见到 mryuan 是在东二走廊的长桌上，那是工高实践面小组的首次碰面。大家介绍完自己的专业后开始分锅，mryuan 说他寒假做过可视化相关的工作，并且熟悉编程语言，所以他可以做 AI 棋的那个题。听起来很靠谱。实践面的最后一天下午，我和另一个同学负责的 keil 出了神秘的编译问题，一直无法解决，mryuan 前来支援，整整 debug 了 6 个多小时，硬是 debug 成功了，令人拍案叫绝，物理意义上的猛得拍了一下桌子。后来我才知道，mryuan 的 c++ 是那几天现学的，这让我肃然起敬。

实践面结束后是专家面，在此之前 mryuan 问我要不要模拟一下面试。很新奇。后来我俩双双被刷。过了几天，邱哥微信问我你认不认识 mryuan，这是他室友。世界好小！有此缘分，五月的时候我问 mryuan 要不要来打数模校赛。此后，便有了许多合作的事情。

mryuan 是电脑高手，我对电脑和 AI 的启蒙全部来自 mryuan。校赛前，我直接把电脑给他，让他教我什么是 miniconda，什么是 github copilot。那时我第一次见到 github 的 agent 可以在一行命令后写出一个贪吃蛇。到了翌年一月，mryuan 帮我开通了 gemini 的 family plan。没有 mryuan，我就是一个原始人。

mryuan 擅长弹吉他，搞乐队，一学期不理头发，颇有文青的气质。本人有幸上过其两次吉他私教，一次在寒假的尧坤楼琴房，一次在玉泉宿舍。吉他是好文明，但我好难坚持。会弹吉他真好。

mryuan 也非常会带小孩。数模美赛时，畅神带上了二年级的妹妹雨姐。mryuan 并非对雨姐照顾有加，有时反而故意和雨姐对着干，但雨姐听他的话，不听我的。mryuan 指示道，带小孩如遛狗，要善于拿捏。持续学习中。
